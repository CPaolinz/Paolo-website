Models, hypertext, and
human experience.

This selected list traces a line from relational database theory and hypertext design to accessibility, digital storytelling, collaboration, and educational chatbots.

This is a curated selection, not a complete bibliography. For formal citations, use the linked publisher or institutional record.

Properties and Update Semantics of Consistent Views

Georg Gottlob, Paolo Paolini, Roberto Zicari

ACM Transactions on Database Systems, 13(4), 486–524.

1991HYPERTEXT

HDM: A Model for the Design of Hypertext Applications

Franca Garzotto, Paolo Paolini, Daniel Schwabe

Proceedings of the Third Annual ACM Conference on Hypertext, pp. 313–328.

Introduces a model for describing the structure, components, and navigation of hypertext applications before implementation.

1993HYPERTEXT DESIGN

HDM: A Model-Based Approach to Hypertext Application Design

Franca Garzotto, Paolo Paolini, Daniel Schwabe

ACM Transactions on Information Systems, 11(1), 1–26.

Develops “authoring-in-the-large”: describing information structures and navigational relationships conceptually, so design decisions can be made before the full application is built.

1995DESIGN & EVALUATION

Hypermedia Design, Analysis, and Evaluation Issues

Franca Garzotto, Luca Mainetti, Paolo Paolini

Communications of the ACM, 38(8), 74–86.

Connects hypermedia design models with usability and evaluation criteria, treating the quality of a digital experience as part of the design process.

Model-driven Development of Web Applications: The AutoWeb System

Piero Fraternali, Paolo Paolini

ACM Transactions on Information Systems, 18(4), 323–382.

Presents a model-driven approach to web application development, extending structured design methods into a development system.

2004ACCESSIBILITY

Listen to a Web Site: Web Accessibility for Educational Cultural-Heritage Websites

Marco Speroni, Nicoletta Di Blas, Paolo Paolini

Proceedings of ED-MEDIA 2004.

Explores accessibility for cultural-heritage and educational websites, including ways for people with visual impairments to interact with web content through a non-visual channel.

2009DIGITAL STORYTELLING

PoliCultura: Introducing Media Literacy in Italian Schools

Nicoletta Di Blas, Paolo Paolini, Caterina Poggi

In Issues in Information and Media Literacy.

Uses PoliCultura as a case study of how school classes can create multimedia stories using an online authoring tool, making digital literacy part of a shared cultural project.

2011EDUCATIONAL DESIGN
